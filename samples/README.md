# Calligraphy Samples

This directory contains scanned samples of calligraphy work to showcase your skills and style to potential customers.

## Sample Images

Each sample should be:
- High-resolution scan (300 DPI minimum)
- Format: PNG or JPG
- Well-lit with good contrast
- Clean background (white or light colored)

## Usage Guidelines

- Showcase variety in your style (formal, modern, whimsical)
- Include different letter combinations to show versatility
- Demonstrate both uppercase and lowercase letters
- Show flourishes and decorative elements
- Watermark samples if posting publicly to protect your work
